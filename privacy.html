BaaBye Privacy Policy

Effective date: 17 September 2026

BaaBye is a digital wellbeing application designed to help users reduce access to distracting applications during user-selected focus or detox sessions.

Installed applications

BaaBye may access limited information about installed launcher applications, including application names and package identifiers, only so users can choose applications to restrict.

BaaBye does not use this information for advertising, profiling, or marketing.

Accessibility Service

Strict Mode uses Android Accessibility Service only to detect when a selected blocked application becomes active so BaaBye can enforce the user-selected detox session.

BaaBye does not use Accessibility access to read messages, passwords, banking information, text entered into other applications, or screen content.

BaaBye does not perform automated gestures or interact with other applications on the user's behalf.

Local data

BaaBye stores app preferences and session configuration locally on the user's device, including selected blocked applications, session duration, restriction mode, and similar settings.

The current version does not require an account or provide cloud synchronisation.

The current version does not send installed-app lists, blocked-app selections, Accessibility events, or detox-session activity to BaaBye servers.

Data sharing and future features

BaaBye does not sell personal data and does not share personal data with advertisers or data brokers.

If future versions add analytics, crash reporting, cloud services, accounts, subscriptions, advertising, or other online services, the policy will be updated as required.

Retention and deletion

Locally stored BaaBye data generally remains on the device until changed, cleared, or the application is uninstalled.

Users may remove locally stored BaaBye data by clearing the app's storage or uninstalling BaaBye.

Permissions and children

BaaBye aims to minimise information access and uses Android permissions only for their intended functionality.

The current version of BaaBye is not specifically directed at children. Any future child or parental-control functionality may require additional protections and updated disclosures.

Your rights and policy changes

Depending on jurisdiction, users may have privacy rights. Since the current version does not operate user accounts or store user data on BaaBye servers, there will normally be no server-side personal data for BaaBye to retrieve or delete.

Material privacy-policy changes may cause BaaBye to ask users to review the updated policy again.
